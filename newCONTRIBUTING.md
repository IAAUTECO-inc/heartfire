Goal: Establish a rigorous process for systems-level contributions.

Contributing to HeartFire
Thank you for your interest in advancing sovereign technology. To maintain the integrity and performance of the HeartFire infrastructure, we adhere to a disciplined contribution workflow.

Design First: For significant architectural changes, please open an "Architecture Decision Record" (ADR) issue for discussion before implementation.

Kernel Standards: All code must comply with our kernel-level performance requirements (low latency, deterministic execution) and C/C++ memory safety standards.

Commit Signing: To ensure provenance and security, all commits must be GPG-signed.

Documentation: Technical contributions must include updated documentation and, where applicable, security impact assessments.
