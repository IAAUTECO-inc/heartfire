# Hearthfire: The Hardened Security Core

## 1. Description
**Hearthfire** is the proprietary security suite and kernel hardening engine of IA_AUT_ECO. It provides the low-level primitives required to run autonomous AI agents in high-risk environments.

## 2. Technical Specializations
* **Enhanced Capsicum Framework:** Advanced capability-based security for NPU/GPU isolation.
* **Deterministic Scheduler:** Real-time priority patches for critical robotic actuators.
* **MAC Policies:** Custom Mandatory Access Control modules for Zero-Trust hardware access.

## 3. Heritage
Hearthfire is built upon the security foundations of the FreeBSD Project. 
* **Core Primitives:** FreeBSD Kernel / TrustedBSD.
* **Enhancements:** IA_AUT_ECO Labs (2026).

Managed under ISO/IEC 5230:2020. See `NOTICE` for provenance and attribution.
